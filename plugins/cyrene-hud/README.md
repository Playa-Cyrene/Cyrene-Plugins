# 昔涟桌面 HUD

版本：0.8.7。作者：**Noimpty**。

原仓库：[LZhWi/Cyrene-Agent-Plugin · codex/cyrene-hud-upstream](https://github.com/LZhWi/Cyrene-Agent-Plugin/tree/codex/cyrene-hud-upstream)。许可与来源见 [LICENSE](./LICENSE) 和 [NOTICE.md](./NOTICE.md)。

在屏幕顶部以胶囊和性能圆环显示电脑状态，支持悬停详情、头像快捷入口和主动消息通知。插件不注册 AI 工具、提示词提供者或渠道，不发送聊天消息、不触发模型推理。

## 使用要求与安装

- Cyrene-Agent 桌面宿主。本提交版为上游兼容实现，`apiVersion: 1`、`deps: []`，无需修改主程序。
- 原生毛玻璃、背景亮度采样和 ASUS 辅助程序面向 Windows x64。原生材质需要 Windows 11 22H2+（构建号 22621 或更新）及系统 .NET Framework 4.x；用户不需要编译器。
- NVIDIA 温度、使用率和独立显存需要系统已有 `nvidia-smi`；没有时尝试 Windows GPU 引擎使用率回退，温度和独立显存保持未知。
- CPU 温度和风扇仅支持具有相应 ATKACPI 接口的 ASUS 设备，需已安装驱动。插件不安装驱动、不请求提权；不支持或无权限时显示未知。

从官方插件仓库下载维护者分发的 ZIP，通过宿主「设置 → 插件 → 导入 ZIP」安装，然后手动启用。点击插件卡片的「打开」进入设置，保存后生效；同 ID 更新保留插件私有存储。

## 显示与交互

- 持续显示，或顶部中央常驻三点小胶囊；默认连续悬停 0.35 秒展开，可设为 0–10 秒。
- 用户选择内存、CPU、GPU、网速、电池、时间和风扇，并拖动或用上下按钮调整顺序。环紧凑排列，悬停一个环显示详细读数。
- GPU 有独立显存时显示双环：外圈 GPU 使用率，内圈显存占用。风扇最多双环，按 CPU、GPU、辅助风扇顺序选择可用读数；百分比为 RPM 除以用户设置的参考满速，默认 6300 RPM，仅影响显示，不控制风扇。
- 网速环内竖排上行和下行数值，单位为 MB/s，详情保留单位。数值为全部网卡合计，虚拟网卡可能重复计数。
- 悬停头像显示状态和心情，遮住重叠圆环；点击可打开设置、Chat、Work、Code、Learn，以及指定已有会话或新建空会话。窗口类型与工作区配置由宿主决定。
- 鼠标离开触发区域和 HUD 窗口后开始隐藏计时；返回任一区域取消。展开和收缩采用 0.3 秒无回弹三次缓动，上边缘对齐。
- 外观可调显示器、高度、圆角、缩放、不透明度、底色、纯色/通透/毛玻璃/云母和鼠标穿透。仅开放顶部居中，宽度按内容计算；悬停模式的云母使用毛玻璃以支持变形。
- 「显示内容」右侧 ⓘ 按钮开合使用说明。「UI 效果测试」模拟悬停、离开与通知，使用固定数据，不移动鼠标、不发送消息、不打开会话、不修改真实未读；停止、保存、关闭设置页或 60 秒无操作后结束。

## 性能与主动消息

主进程在收起或隐藏时每 5 秒采集性能，展开时按 1 秒目标间隔采集并请求即时更新。慢查询不重叠，实际间隔不短于系统查询耗时；只有时间指标及 UI 模拟期间不采集硬件。禁用插件会停止定时器、销毁窗口及辅助进程、中止查询。CPU 和网速首次缺少差分基准，可能暂时显示未知；失败值不伪装为零。

新增主动消息展开为头像和摘要，停稳 2 秒后缩回。展开 HUD 后，头像右上显示实心圆、空心数字的未读角标；点击通知或角标打开会话，成功后清除此次打开对应的未读，失败及随后新增的消息保留。首次启用跳过旧历史，重启不重放已通知消息。在其他窗口阅读暂不能同步清除 HUD 未读。

## 网络、数据与存储

插件自身没有 HTTP 请求、遥测、在线更新或自动下载，不需要 API key；不会把硬件读数、屏幕像素或消息摘要发送给模型或外部服务。

通过 Node 和 Windows 查询读取 CPU 累计时间/频率、内存、GPU、网卡累计收发、电池、开机时长和磁盘容量统计，不读取用户文件内容。设置及通知游标、消息/会话 ID、时间戳、未读摘要通过 `ctx.storage` 保存于插件私有存储；每条摘要最多 100 个字符。不直接修改宿主聊天存档或其他插件数据。

主动消息通过宿主分页接口在 preload 中读取 `proactive-chat` 会话，过滤新增助手文本，仅持久化 ID、时间及摘要；HUD 页面接收通知投影。状态与心情读取当前宿主值。`model-config:get` 返回配置只用于提取连接状态和运行同步模式，其他字段不向页面投影、不写文件或日志。会话下拉框接收 ID、标题与模式。

可见时，每秒在 HUD 固定空白边缘读取 18 个屏幕像素，临时缓冲立即释放，只返回亮度及几何信息，不保存截图或提供给模型。毛玻璃使用 Windows 合成背景画刷与高斯模糊，不将截图用于渲染。

## 子进程及二进制

进程以隐藏窗口方式启动。命令固定，参数来自内部句柄、规范化数值或固定查询，不执行用户输入的 shell 命令。

| 程序 | 用途与参数 | 超时/清理 |
| --- | --- | --- |
| `GlassHost.exe` | 随包 Windows x64 C# 程序；圆角模糊、亮度采样、置顶遮挡检测。参数为内部 HWND；通透/云母模式附固定 `--sample-only`。标准输入传递几何和背景样式 | 启动 8 秒未就绪则回退；切换纯色、禁用或宿主退出时结束 |
| `AsusSensors.exe` | 随包 C# 程序，打开 `\\.\ATKACPI`，发出固定 DSTS 温度及三种风扇查询；无用户参数，不写设备设置 | 1.5 秒超时，传感器均不可用时退避 30 秒 |
| 系统 `powershell.exe` | `-NoProfile -NonInteractive -Command` 执行代码内固定的 CIM/网卡统计脚本 | 8 秒超时，禁用时中止 |
| 系统 `nvidia-smi` | 固定读取 GPU 0 温度、使用率及已用/总显存，CSV 输出，不修改 GPU 设置 | 3 秒超时，失败后 30 秒重试，禁用时中止 |

原生源码见原仓库 [GlassHost.cs](https://github.com/LZhWi/Cyrene-Agent-Plugin/blob/codex/cyrene-hud-upstream/native/GlassHost.cs) 和 [AsusSensors.cs](https://github.com/LZhWi/Cyrene-Agent-Plugin/blob/codex/cyrene-hud-upstream/native/AsusSensors.cs)。它们使用 Windows 系统 .NET Framework 编译器构建，GlassHost 引用系统 WinMetadata；提交目录只含运行必需文件，源码和构建流程保留在原仓库。

## 宿主 IPC 与兼容边界

`deps: []`，不申请 SDK 模型、渠道、密钥、记忆或工具能力。使用宿主 Electron 环境、插件私有 IPC、存储及以下固定内部入口。内部 IPC 不属于稳定的 SDK 能力契约，空 `deps` 也不意味着隔离了插件的 Node 权限；升级宿主时需要重新验证。

| 内部入口 | 目的 |
| --- | --- |
| `chats:list` | 按模式列举会话、识别主动消息会话 |
| `chats:create` | 用户点击头像且选择新建时创建空会话 |
| `chats:open-in-react-window` | 用户点击头像或通知时打开会话 |
| `chats:get-page` | 主动消息分页读取与摘要提取 |
| `chats:changed` | 监听变化；另有 5 秒补偿检查 |
| `settings:request-switch-section` | 用户选择设置入口后打开设置 |
| `sidebar:open-settings` | 上述设置入口未注册时的既有事件回退 |
| `runtime-state:get` | 读取状态与心情 |
| `model-config:get` | 读取连接状态及运行同步模式，不调用模型 |

本地集成版另依赖扩展宿主的 `window-navigation`；官方提交版不能用本地集成版代替。

## 已知限制与更新

- ASUS 之外的 CPU 温度/风扇可能不可用；GPU 引擎总和回退属于估算。未支持读数显示未知。
- 原生材质受 Windows 透明效果、节能及设备支持影响；失败时回退纯色，节能时暂停模糊。独占全屏游戏、多显示器混合 DPI 和实际鼠标穿透需逐环境验证。
- 回归和隔离 Electron 检查使用模拟数据/输入，不等于完整宿主真实使用验证。普通窗口背景被其他应用覆盖时，背景稳定性复测无法取得有效结论。
- 本次提交的宿主提交号、官方 SDK 校验及测试证据见 PR 描述和验证记录，不声称兼容所有宿主版本。
