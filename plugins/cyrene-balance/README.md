# 昔涟 · 桌面桌宠（cyrene-balance）

常驻桌面的那一只昔涟：余额与今日消费、要你回答的问题、危险操作的确认、当前任务走到哪一步、机器的 CPU / GPU / 内存状态，全部收在她身上。

> 当前版本：**10.4.3**（2026-10-25）
> 插件 id：`cyrene-balance`｜作者：bestlike093｜需要 Cyrene 插件系统（`apiVersion: 1`）

---

## 0. 五分钟上手

第一次安装照这五步走，就能看到桌宠并开始用：

1. **装插件**：下载 `cyrene-balance-10.4.3.zip` → Cyrene **设置 → 插件 → 从本地安装** → 选中 ZIP。压缩包里已经带 `cyrene-balance/` 顶层目录，不要再手动套一层。
2. **启用**：在插件列表里打开「昔涟 · 桌面桌宠」，立绘出现在桌面右下角，默认跟着 Cyrene 主窗口。
3. **填 Key**：右键立绘 →「打开设置」→ 填 DeepSeek API Key；也可以直接说「把 DeepSeek Key 设成 sk-…」。Cyrene 里已有 DeepSeek 模型配置的话，插件会只读复用，不填也能先看到余额。
4. **设额度**：右键 →「余额与额度」→ 设余额提醒阈值（默认 20 元）与今日额度（0 表示关闭）。
5. **试一次**：在对话里说「今天用了多少」，看余额气泡是否更新；再右键 →「♪ 说句话」，确认台词气泡和小表情正常。

五步都正常，剩下的就是按自己的习惯调外观了，见第 5、6 节。

---

## 1. 这是什么

`cyrene-balance` 不是单纯的余额挂件，而是桌面上唯一的常驻桌宠。它同时承担五件事：

| 能力 | 说明 |
| --- | --- |
| 余额观测 | 定时读取 DeepSeek 账户余额、今日消费、今日充值、当前峰谷时段 |
| 提问卡 | Agent 需要你选择或补充信息时，桌宠展开成 420×580 的卡片让你作答 |
| 审批卡 | 危险操作确认同样由桌宠接管，作答或结算后自动收回 |
| 任务气泡 | 主窗口「当前任务」的进度同步成气泡，显示完成数、进度条和正在做的那一步 |
| 状态面板 | 头顶面板显示头像、心情、模型、CPU / GPU / 内存、网速与电量，三档详细度可切 |

旧版独立的顶部 HUD 插件能力已经并入本插件，不需要再常驻第二个窗口。

## 2. 安装与启用

1. 下载压缩包：[zips/cyrene-balance-10.4.3.zip](https://github.com/bestlike093/cyrene-balance/raw/main/zips/cyrene-balance-10.4.3.zip)（约 20.2 MB）。SHA-256 以 [v10.4.3 Release](https://github.com/bestlike093/cyrene-balance/releases/tag/v10.4.3) 页显示的为准。下载后可以这样核对：

   ```powershell
   Get-FileHash .\cyrene-balance-10.4.3.zip -Algorithm SHA256
   ```
2. 在 Cyrene 的 **设置 → 插件** 里选择「从本地安装」，选中 ZIP；插件目录里必须保留 `cyrene-balance/` 这一层。
3. 安装完成后在插件列表里启用 `昔涟 · 桌面桌宠`。
4. 启用后立绘会出现在桌面右下角，默认跟随 Cyrene 主窗口。

如果启用后没有看到立绘：

- 确认插件状态是「已启用」，不是「已安装但停用」。
- 看是否被其他窗口挡住，或立绘被拖到了屏幕外。右键任务栏里的 Cyrene 退出重开一次，位置会按主窗口重新夹取。
- 检查 `设置 → 插件 → 昔涟 · 桌面桌宠` 里「自动打开桌宠」是否被关掉。

## 3. 第一次配置

### 3.1 API Key 的两种来源

插件按以下顺序找 Key：

1. **插件内单独保存的 Key**（推荐）
   - 右键立绘 → 打开设置 → 填入 DeepSeek API Key；
   - 或者在对话里直接说「把 DeepSeek Key 设成 sk-...」。
   - Key 保存在宿主提供的加密密钥存储 `ctx.deps.secrets` 里，不写进普通插件设置。
2. **跟随 Cyrene 的模型配置**
   - 没有单独填 Key 时，插件会只读 `%APPDATA%\Cyrene\model-settings.json`，取 `baseUrl` 含 `api.deepseek.com` 的模型配置里的 Key。
   - 这一步只读，不修改该文件。

两种来源都没有时，余额会显示为空或报错，立绘本身仍然正常显示。

### 3.2 建议先做的三件事

- 设一个余额提醒阈值（默认 20 元）。
- 设一个今日额度（0 表示关闭），避免一天不知不觉花超。
- 选一个自己喜欢的气泡显示方式：轮播 / 只看余额 / 只看台词 / 只看今日额度 / 只看余额。

## 4. 桌面上的交互

### 4.1 立绘

- 透明无边框窗口，连窗口底色也是透明的。
- 默认跟随 Cyrene 主窗口，贴在右下角；关掉「跟随 Cyrene 窗口」后可以拖到屏幕任意位置，并记住坐标。
- 8 张姿态（`frame-01` ~ `frame-08`）自动轮换，默认 45 秒换一次，也可以手动「换一个姿势」。
- 5 张情绪特写（平静 / 自信 / 开心 / 俏皮 / 严肃）按状态叠加切换。
- 44 张去白底小表情嵌在台词气泡里。

**素材的最原始来源**

这些立绘和表情不是本插件画的，也不是从第三方图包里收集的。追溯链只有三层：

1. **最原始的一层**：《崩坏：星穹铁道》里角色「昔涟」的官方立绘、表情与头像，版权归 HoYoverse / 米哈游。
2. **第二层**：Cyrene 客户端把其中一部分整理成自带素材库，打包在安装目录的 `resources/app.asar` 里；同一批文件也随 [Cyrene-Agent](https://github.com/Playa-Cyrene/Cyrene-Agent) 开源仓库发布。
3. **第三层**：本插件按文件名从这份素材库里取用，只做去白底、缩放与透明化，没有重绘，也没有改动角色设定。

| 素材 | 数量 | 素材库内路径（与 Cyrene-Agent 仓库同名文件一致） | 本插件做了什么 |
| --- | --- | --- | --- |
| 姿态立绘 `frame-01` ~ `frame-08` | 8 | `assets/ui/cyrene-thinking-loop/` | 原样使用 |
| 情绪特写 `calm` / `confident` / `love-happy` / `playful` / `serious` | 5 | `dist/renderer/stickers/` | 原样使用 |
| 台词小表情 `Airkiss` ~ `weeploud` | 44 | `dist/renderer/stickers/`（原始为 JPG） | 去白底，转成 256×256 PNG |
| 状态面板头像 `mimi` | 1 | `dist/renderer/icons/mimi.png` | 原样使用 |

Cyrene 使用的 Live2D 模型（`models/cyrene/`）由 B 站 UP 主 [@是依七哒](https://space.bilibili.com/457683484) 制作，授权范围见 Cyrene-Agent 的 `MODEL_LICENSE.md`。本插件只使用静态立绘与贴纸，不包含这个 Live2D 模型。

想自己核对：用 asar 工具列出 `resources/app.asar` 的内容，能在上表路径找到同名文件；再对比本插件 `assets/`，差别只有透明底和尺寸。

### 4.2 头顶状态面板

状态面板默认**关闭**，在右键菜单「桌宠行为 → 状态面板」里打开。打开后有三档详细度：

| 档位 | 显示内容 |
| --- | --- |
| 详细 | 头像、心情、模型；CPU / GPU / 内存三只圆环；下行给实时下载、上传与电量 |
| 简版 | 一行状态，信息密度最低 |
| 简版2 | 默认收成头像 + 心情 / 模型，点一下才展开 CPU · 内存，再点收起 |

数据来源与刷新节奏：

- CPU 与内存来自 `node:os`，每 3 秒推一次快照。
- GPU、网速、电量由一次固定的 PowerShell 采样拿齐，采样结果缓存 6 秒，失败后 30 秒再试。
- 读不到的项目会留空，不会弹错误，也不会阻塞桌宠。

### 4.3 双气泡

| 气泡 | 内容 |
| --- | --- |
| 信息气泡 | 余额 / 今日已用 / 峰谷时段 |
| 台词气泡 | 昔涟台词 + 小表情 |

气泡显示方式（`bubbleMode`）五种：

- `rotate`：信息与台词轮播（默认）
- `info`：只显示余额信息
- `talk`：只显示台词
- `today`：只看今日额度
- `balance`：只看余额

气泡弹出时立绘会自动缩小让位，收起后复原，不挡住金额。

### 4.4 任务气泡

主窗口「当前任务」的进度会同步成一只任务气泡：

- 显示完成数、进度条、正在做的那一步。
- 单击气泡展开 / 收起清单。
- 双击直接打开主窗口的任务面板。

任务气泡和状态面板都在右键菜单「桌宠行为」里，可以单独关闭。

### 4.5 提问卡

Agent 需要你选择或补充信息时，桌宠会从立绘展开成 420×580 的卡片：

- 选项、多选、自由填写都在卡片里完成。
- 主界面要不要同时保留一张原生提问卡，由「提问与确认 → 主界面提问卡」决定，默认保留。
- 默认保留原生卡是故意的：桌宠没接住的时候，至少不会出现两边都空着、对话一直等、点哪儿都没反应的情况。确认桌宠稳定后再手动隐藏。

### 4.6 审批卡

危险操作确认也由桌宠接管：

- 展开成卡片显示操作内容、风险等级和可选项。
- 你作答后，插件把结果回传给宿主，窗口自动收回空闲尺寸。
- 如果宿主没有提供对应的审批 IPC，卡片会退化成只读展示，这时请回到主窗口完成确认。

## 6. 设置面板

在 **设置 → 插件 → 昔涟 · 桌面桌宠** 打开的设置页，覆盖以下项目：

- **余额**：提醒阈值、今日额度、刷新间隔（最短 30 秒）
- **外观**：立绘缩放、姿态轮换与间隔、气泡档位、气泡宽度 / 高度、余额字号、台词字号、小表情大小、气泡位置、轮播间隔
- **提问与确认**：是否由桌宠回答提问、主界面提问卡显示 / 隐藏、工具审批是否交给桌宠
- **桌宠行为**：任务气泡、状态面板开关与详细度、跟随 Cyrene 窗口、自动打开桌宠
- **Key**：单独保存 / 替换余额查询用的 DeepSeek Key

大部分选项在右键菜单和设置页都能改，改完立即写回 `ctx.storage`。

## 7. 对话里的用法

插件注册了 6 个工具，所有 id 以 `cyrene-balance_` 为前缀：

| 工具 id | 用途 | 风险 |
| --- | --- | --- |
| `cyrene-balance_query` | 查询余额、今日消费、今日充值、峰谷时段；`view` 可选 `all` / `today` / `balance` | 只读 |
| `cyrene-balance_set_threshold` | 设置提醒阈值与今日额度 | 写入 |
| `cyrene-balance_set_key` | 保存余额查询专用 Key | 写入 |
| `cyrene-balance_status` | 查看阈值、额度、气泡模式、刷新间隔、Key 来源与上次查询 | 只读 |
| `cyrene-balance_set_view` | 切换气泡显示范围 | 写入 |
| `cyrene-balance_history` | 查看最近 7 天每日消费 | 只读 |

可以直接这样说：

- 「还有多少钱？」
- 「今天用了多少，额度还剩多少？」
- 「余额低于 50 提醒我。」
- 「今天额度改成 40 元。」
- 「只看今日额度。」
- 「把这周每天花的钱列出来。」

插件还会通过 prompt provider 把当前余额摘要注入对话上下文，所以正常情况下昔涟能直接接上你的余额话题，不需要你每次重复报数。

## 8. 数据、网络与权限

### 8.1 网络

只访问一个外部地址：

```text
GET https://api.deepseek.com/user/balance
Authorization: Bearer <你的 DeepSeek API Key>
```

- 响应体上限 200 KB。
- 不上传对话内容，不向其他域名发请求，不做统计上报。
- 请求失败只在本地面板提示，不会重试到其他域名。

### 8.2 数据存储

| 位置 | key | 内容 |
| --- | --- | --- |
| `ctx.storage` | `settings` | 阈值、额度、刷新间隔、气泡与字号、窗口位置（不含 API Key） |
| `ctx.storage` | `ledger` | 最近 7 天的每日消费 / 充值账本 |
| `ctx.deps.secrets` | `deepseekApiKey` | 手动填写的 DeepSeek API Key，由宿主加密保存 |

另外会在插件数据目录写一个诊断日志：

```text
%APPDATA%\Cyrene\plugin-data\cyrene-balance\ask-debug.log
```

日志只记录提问链路的四个节点（收到提问、卡片下发、卡片渲染、作答），超过 64 KB 自动清空，不记录对话正文。

旧版本写在 `settings.apiKey` 里的 Key 会在首次读取时自动迁移到加密存储，并从普通设置里删除。

### 8.3 读取的文件

| 行为 | 说明 |
| --- | --- |
| 读 `%APPDATA%\Cyrene\model-settings.json` | 只读，仅取 DeepSeek profile 的 Key 与模型名；不修改 |
| 读插件目录内 `widget.html`、`card.html`、`settings.html`、`assets/` | 立绘、表情、音效随插件分发 |
| 写 `plugin-data/cyrene-balance/ask-debug.log` | 提问链路诊断，64 KB 上限 |

### 8.4 子进程与系统采样

这一版会启动一个固定脚本的 PowerShell 子进程：

```text
powershell.exe -NoProfile -NonInteractive -Command <固定脚本>
```

脚本只做三件事：

- `Get-NetAdapterStatistics` 读网卡累计收发字节，用于算实时网速；
- `Get-CimInstance Win32_Battery` 读电量与充电状态；
- `Get-CimInstance Win32_PerfFormattedData_GPUPerformanceCounters_GPUEngine` 读 GPU 利用率。

脚本内容是常量，不拼接用户输入，不接收外部参数，超时 8 秒，`windowsHide: true` 隐藏窗口。

### 8.5 宿主能力

- `ctx.storage`、`ctx.deps.secrets`
- `ctx.registerTool`、`ctx.registerIpc`、`ctx.registerPromptProvider`
- `electron.BrowserWindow`、`webContents`、`Menu`、`screen`
- 拦截的通道：`cyrene.choice`、`cyrene.choice.dismiss`、`permission:approval-request`、`permission:approval-settled`、`cyrene.todo`、`agui:event`
- manifest 声明 `deps: ["secrets"]`

## 9. 常见问题

### 桌宠没有弹出问题，怎么看

先看 `ask-debug.log` 的四行：

| 日志行 | 含义 |
| --- | --- |
| `桌宠提问接管已启动 build=...` | 新代码已加载，拦截在跑 |
| `收到提问 kind=ask questions=N` | 拦到了提问事件 |
| `卡片已下发 kind=ask id=...` | 已经发给桌宠窗口 |
| `卡片已渲染 kind=ask id=...` | 桌宠真的画出来了 |

对照判断：

- 一行都没有 → 插件还是旧进程，重启 Cyrene 或停用再启用本插件。
- 只有「收到提问」没有「已下发」→ 桌宠窗口没起来。
- 有「已下发」没有「已渲染」→ 卡片在 iframe 里没画出来。
- 四条齐全却没看到 → 窗口跑到屏幕外或被其他窗口遮住了。

### 余额一直是空的

依次检查：Key 是否有效、Key 是否有余额查询权限、`baseUrl` 是否为 `api.deepseek.com`、网络是否能访问该域名、是否被代理拦截。

### 状态面板的 GPU / 网速 / 电量是空的

这三项依赖 Windows PowerShell 与相关 CIM 类。系统策略禁用 PowerShell、杀毒软件拦截子进程、精简版系统缺少性能计数器时，会留空而不报错。CPU 与内存在任何 Windows 上都能读。

### 立绘挡住别的东西

- 右键 → 视图 → 缩小；
- 或关掉「跟随 Cyrene 窗口」后拖走；
- 或在右键菜单里「关闭桌宠」，需要时再启用。

### 升级后设置丢了

设置按 key 存在 `ctx.storage`。如果宿主升级改变了存储位置或命名空间，旧设置可能读不到，插件会回退到默认值。升级前可以先把阈值、额度、外观记下来。

## 10. Agent / Cyrene 升级后可能产生的后果

这一节写给准备升级 Cyrene 或 Agent 的人。桌宠不是独立程序，它寄生在宿主进程里，靠宿主提供的 IPC、事件、窗口 API 和存储工作。宿主升级后，下面这些地方都可能变。

### 10.1 插件可能直接不加载

- 插件 manifest 声明 `apiVersion: 1`。宿主升级后如果提高 API 版本、改变 manifest 字段校验、或不再接受 `settingsPanel` / `settingsSection` 写法，插件会被标记为不兼容，表现为「已安装但无法启用」或「启用后没有反应」。
- `deps: ["secrets"]` 如果被宿主改名或移除，插件启动会失败。

**你会看到**：插件列表里状态异常，日志里出现 manifest 校验错误。
**怎么办**：先停用插件，确认 Cyrene 版本，等插件适配新 API 后再启用；不要反复重装。

### 10.2 提问卡与审批卡可能失效

它们依赖宿主的 `cyrene.choice`、`cyrene.choice.dismiss`、`permission:approval-request`、`permission:approval-settled` 事件，以及 `choice:resolve` / `permission:approval-resolve` 回传通道。

宿主升级如果改了事件名、载荷结构、选项字段或回传通道：

- 轻则卡片显示但按钮无响应；
- 重则完全拦不到提问，桌宠不展开；
- 如果同时隐藏了主界面原生卡，可能出现「两边都没有卡、对话一直等」的情况。

**你会看到**：`ask-debug.log` 停在「收到提问」或「卡片已下发」，没有「卡片已渲染」；或者卡片能显示但点不动。
**怎么办**：先把「主界面提问卡」恢复为显示，保证有原生卡兜底；再等插件适配。

### 10.3 任务气泡可能不再更新

任务气泡依赖 `cyrene.todo` 事件和 `cyrene:open-task-panel` 通道。宿主升级如果改了待办事件名、进度字段，或不再向前台窗口广播，任务气泡会停在旧进度，双击也打不开任务面板。

**你会看到**：气泡里的完成数不动，或双击只把主窗口带到前台。
**怎么办**：改用主窗口的任务面板，等插件更新。

### 10.4 状态面板数据可能缺失或错位

- GPU、网速、电量依赖 PowerShell 与 Windows CIM 类。宿主升级若改变子进程策略、沙箱权限或 `execFile` 行为，采样会失败，三项留空。
- CPU / 内存依赖 `node:os`，一般不受影响。
- 模型名来自 `model-settings.json`；宿主升级若改变该文件结构或字段名，模型名会显示为未知，但余额查询不受影响。

### 10.5 窗口行为可能异常

桌宠窗口用 `BrowserWindow` 的透明、无边框、置顶、跳过任务栏、鼠标穿透等能力。Electron 大版本升级后可能出现：

- 透明背景变黑或变白；
- 立绘无法拖动，或拖动后位置漂移；
- 窗口跑到屏幕外、缩放后不回到可视区；
- 多显示器 / 高 DPI 下坐标偏移。

**怎么办**：右键 → 视图 → 重置位置 / 关闭再打开桌宠；仍异常就临时停用插件。

### 10.6 余额数据可能中断或失真

- DeepSeek 的 `/user/balance` 接口若变更路径、返回结构或鉴权方式，余额会刷新失败，面板显示旧数据或空值。
- 宿主升级若改变 Key 的读取方式或加密存储实现，插件可能拿不到 Key。
- 「今日消费」是观感记账：用相邻两次余额差推算，不是官方账单。宿主升级导致刷新间隔变化、请求并发变化、多设备同时使用、赠送额度到账，都会让这个数字偏大或偏小。

### 10.7 设置与历史账本可能丢失

`ctx.storage` 的命名空间、序列化方式、迁移策略由宿主决定。宿主升级若重置插件数据目录，阈值、额度、气泡设置和 7 天账本会一起丢失。降级插件版本时，新版本写入的字段也可能被旧版本忽略。

### 10.8 插件被宿主策略限制

新版宿主可能增加权限声明、网络白名单、子进程审批、插件签名校验。届时：

- 首次启动 PowerShell 采样可能弹审批；
- 访问 `api.deepseek.com` 可能被网络策略拦截；
- 未签名插件可能被默认禁用。

这些都属于宿主侧策略，不是插件能绕过的。

### 10.9 一句总结

**升级 Cyrene / Agent 前，先备份 `%APPDATA%\Cyrene\plugin-data\cyrene-balance\`，并确认原生提问卡没有被隐藏。** 桌宠失效时，主窗口的原生能力仍然可用；把插件停用不会影响 Agent 本体。

### 10.10 升级前后检查清单

升级前花一分钟做这几件事，出问题时能少走很多弯路：

- **备份数据目录**：把 `%APPDATA%\Cyrene\plugin-data\cyrene-balance\` 整个复制到别处，账本和设置都在里面。
- **记下关键配置**：余额阈值、今日额度、气泡显示方式、图标缩放，各记一行就够。
- **确认兜底开着**：`提问与确认 → 主界面提问卡` 保持「照常显示」，不要让桌宠成为唯一的作答入口。
- **留一份旧版压缩包**：`zips/cyrene-balance-10.4.2.zip`，需要回退时直接本地安装。
- **确认 Cyrene 版本号**：升级失败时，这个版本号是判断兼容性的第一手信息。

升级后按这个顺序检查：

1. 插件列表里状态是否正常，能否启用；不能启用就先停用，不要反复重装。
2. 立绘是否出现、能否拖动、是否在屏幕可视区内。
3. 余额是否刷新出数字；右键「立即刷新余额」试一次。
4. 对话里发一次提问，看桌宠是否展开成卡片并能作答。
5. 打开状态面板，看 CPU / 内存是否正常，GPU / 网速 / 电量允许为空。
6. 看一眼 `ask-debug.log`，确认提问链路四个节点齐全。

任何一步不对，先按第 9 节排查；确认是宿主升级导致的后，停用插件等适配，这期间主窗口的功能照常可用。

## 13. 源码与结构

```text
cyrene-balance/
  manifest.json     插件清单（apiVersion 1、id、版本、deps）
  index.cjs         入口：工具、IPC、窗口、采样、提问拦截
  widget.html       桌面立绘与气泡
  card.html         提问卡 / 审批卡
  settings.html     设置面板
  README.md         本说明书
  assets/           8 张姿态、5 张情绪、44 张表情、音效
```

入口 `index.cjs` 只 `require` Node 内置模块（`node:fs` / `node:path` / `node:https` / `node:os` / `node:child_process`）与宿主提供的 `electron`，没有目录外的 npm 依赖，没有压缩混淆，没有 `eval` / `new Function` / 动态 `require`。
