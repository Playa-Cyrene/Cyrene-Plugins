# 昔涟 · 桌面桌宠（cyrene-balance）

桌面上只留这一只昔涟：余额与今日消费、要你回答的问题、危险操作的确认、当前任务走到哪一步，全部收在她身上。立绘可以拖到屏幕任意位置，气泡按场景轮换，余额告急时换表情提醒你。

## 统一桌宠

以前的 `cyrene-ask-pet` 已并入本插件，不再需要单独安装。

- **提问卡**：Agent 需要你选择或补充信息时，桌宠展开成 420×580 的卡片，原生提问卡被收起
- **审批卡**：危险操作确认同样由桌宠接管；作答或结算后自动收回空闲尺寸
- **任务框**：主窗口「当前任务」的进度会同步成一只任务气泡，显示完成数、进度条和正在做的那一步
  - 单击气泡展开/收起清单；双击直接打开主窗口的任务面板
- **状态**：空闲 / 工作中 / 等待回答 / 等待确认，立绘与表情跟着换

右击立绘的「桌宠行为」菜单可以逐项开关：是否接管提问、是否接管审批、隐藏原生卡片、是否显示任务气泡、是否隐藏原生任务面板。

## 功能

- **桌面立绘**：透明无边框窗口（连窗口底色也是透明的），默认跟随主窗口，也可以自由拖动并记住位置；8 种姿态自动轮换，5 种情绪特写叠影切换
- **余额观测**：定时请求 DeepSeek 余额接口，展示账户余额、今日消费、今日充值、当前峰谷时段
- **双气泡**
  - 信息气泡：余额 / 今日已用 / 峰谷一行展示
  - 台词气泡：昔涟台词 + 小表情，内置 44 张去白底表情
  - 气泡模式可切换：`轮播` / `只显示余额信息` / `只显示台词` / **`只看今日额度`** / **`只看余额`**
- **今日额度**：可设今日消费上限（0 表示关闭），右键菜单里有 10/20/30/50/100 元快捷档位和「自定义…」，也可以在对话里直接说「今天额度改成 40 元」
  - 用掉 80% 时提示「接近额度上限」
  - 超过上限时进入**特殊提醒**：气泡换成高亮粉红、持续脉动、播放两段提示音、立绘换成严肃表情，台词也换成额度专属文案
  - 只看今日额度时，立绘上的主数字会切换成「今日已用」，气泡只报额度和剩余
- **一套可调外观**：气泡尺寸（紧凑 / 标准 / 宽松 / 超大）、余额字号五档、台词字号五档、小表情四档、立绘缩放、气泡位置、轮播间隔
- **让位动画**：气泡弹出时立绘自动缩小，收起后复原，不挡住金额
- **提醒**：余额低于阈值、今日消费接近或超过额度时，切换表情与台词，并播放提示音
- **观感记账**：每次读到余额与上一次比较，下降记为今日消费，上升记为充值；充值不会冲掉已经记录的消费；跨天自动归档，保留 7 天
- **对话工具**：查询余额（可只看今日额度 / 只看余额）、设置阈值与今日额度、切换气泡显示范围、单独指定 API Key、查看当前状态、查看最近 7 天消费

## 使用方式

1. 安装后在 **设置 → 插件** 里启用，立绘会出现在桌面
2. 填 API Key：右键菜单里填入 DeepSeek Key；也可以在对话里让昔涟保存
   - 手动填写的 Key 会存进宿主的**加密密钥存储**（`ctx.deps.secrets`），不写进普通插件设置
   - 没有手动填写时，插件会尝试从 Cyrene 的 `model-settings.json` 里读取 `baseUrl` 含 `api.deepseek.com` 的模型配置中的 Key
3. 右键立绘可以调整外观、刷新间隔、气泡模式，或打开设置
4. 想让 Agent 直接查余额时，说「还有多少钱」「今天花了多少」即可

## 网络访问

只访问一个地址：

```text
GET https://api.deepseek.com/user/balance
Authorization: Bearer <你的 DeepSeek API Key>
```

- 用于读取余额与今日用量，响应体上限 200 KB
- 不上传到其它任何地址，不上传对话内容，不做统计上报
- 请求失败只在本地面板提示，不重试到其它域名

## 数据存储

| 位置 | key | 内容 |
| --- | --- | --- |
| `ctx.storage` | `settings` | 阈值、预算、刷新间隔、气泡与字号等外观选项、窗口位置（不含 API Key） |
| `ctx.storage` | `ledger` | 最近 7 天的每日消费/充值账本 |
| `ctx.deps.secrets` | `deepseekApiKey` | 手动填写的 DeepSeek API Key，由宿主加密保存 |

不写入插件目录以外的文件。旧版本写在 `settings.apiKey` 里的 Key 会在首次读取时自动迁移到加密存储并从设置中删除。

## 读取的文件与权限

| 行为 | 说明 |
| --- | --- |
| 读 `%APPDATA%\Cyrene\model-settings.json` | 只读，仅取 `baseUrl` 含 `api.deepseek.com` 的 profile 的 `apiKey`，用于上面的余额请求；**不修改该文件** |
| 读插件目录内 `widget.html`、`assets/` | 立绘、表情、音效，随插件一起分发 |
| `electron.BrowserWindow` | 创建透明无边框桌宠窗口 |
| 网络 | 仅 `api.deepseek.com` 的一次 GET |
| 子进程 / 外部命令 | 不使用 |

## 风险说明

- 插件与 Cyrene 运行在同一进程，拥有完整 Node 权限；本插件自身的行为限定在上表范围内
- API Key 优先保存在宿主加密密钥存储里，只用于向 `api.deepseek.com` 发起余额查询；旧版本留在普通设置里的 Key 会自动迁移并清除
- 桌宠窗口常驻桌面，可以在右键菜单里关闭或停用插件

## 版本

**9.6.0**

- 新增「今日额度」：右键菜单快捷档位（10 / 20 / 30 / 50 / 100 元）+「自定义…」输入，也可以在对话里直接调节
- 额度特殊提醒：用掉 80% 提示接近上限；超过上限时气泡高亮脉动、两段提示音、严肃表情和额度专属台词
- 气泡显示方式新增「只看今日额度」与「只看余额」；只看今日额度时主数字切换为今日已用
- 查询工具新增 `view` 参数（all / today / balance），并新增 `cyrene-balance_set_view` 切换显示范围
- 状态工具会显示今日额度使用比例与当前气泡显示方式

**9.5.1**

- 桌宠窗口补上透明底色（`backgroundColor: #00000000`），Windows 上不再出现白底
- API Key 改存宿主加密密钥存储，旧数据自动迁移
- 跨天归档时保留历史账本，不再丢掉前一天的记录
- 跟随模式按主窗口屏幕坐标定位，主窗口不在左上角时也能贴住右下角
- 独立模式恢复上次保存的坐标，并按当前工作区夹取
- 刷新失败（缺 Key / 401 / 网络）会把错误显示在挂件气泡里
- 今日消费跨过预算时也会触发提醒
- 插件被停用时取消尚未执行的自动打开

**9.5.0**

- 主立绘从 1 张扩到 8 张姿态，默认每 45 秒轮换一次
- 右键菜单新增「立绘」：自动轮换开关、换一个姿势、轮换间隔（20 / 45 / 90 / 180 秒）

**9.4.0**

- 双气泡：信息气泡与台词气泡分离，支持轮播 / 单显
- 台词字号独立五档（10 / 12 / 14 / 16 / 18），与余额字号互不影响
- 小表情嵌入台词气泡，四档大小
- 气泡尺寸四档只调整内边距与圆角，不再覆盖字号
- 气泡弹出时立绘按实际高度自动缩小让位，收起后复原

## 源码

插件按 Cyrene 插件 SDK 结构开发，入口为自包含的 `index.cjs`，运行时依赖仅 Node 内置模块与宿主提供的 `electron`。
