# 米家智能家居控制（mijia-control）

> Cyrene Plugin API v1 · 自包含 · 第三方工具，与小米公司无关联、未获授权。

扫码连接你的小米 / 米家账号，扫描并按房间分组展示账号下的智能家居设备（灯、插座、风扇、空气净化器、加湿器、扫地机器人、空调等），并支持**对话**与**面板**两种方式操控设备。

## 功能

- **扫码连接**：用已登录该小米账号的米家 / 小米运动健康 App 扫码授权，凭证加密保存在本机，退出登录即删除。
- **设备扫描**：插件启动、打开面板时各扫描一次，此后按设定间隔（默认 5 分钟）定时扫描；数据源为米家云端设备列表，并对局域网做 best-effort 的 miio UDP 探测。
- **按房间分组**：仿米家样式，把不同位置（客厅 / 卧室 …）的设备分区展示；每行两张圆角卡片，15 类设备（灯 / 风扇 / 插座 / 空净 / 加湿器 / 扫地机 / 摄像机 / 门锁 / 窗帘 / 传感器 / 开关 / 影音 / 空调 / 穿戴等）各有手绘线性 SVG 图标，随在线 / 离线状态自动变色。
- **自动功能控件（MIoT-Spec 驱动）**：点击卡片打开操作面板，插件读取该型号的公开 MIoT-Spec，**自动生成本机应有的控件**——开关（bool）、滑块（带范围数值，如亮度 / 色温 / 档位）、下拉（枚举，如模式）、动作按钮（如风扇 Turn On/Off、扫地机回充）；并回填当前值。控件标签已内置 60+ 词条的中文词典（含重名消歧，如「灯光·模式」）。
- **「仅展示」识别**：无可写属性也无动作的设备（手表 / 手环 / 纯传感器）标记为「仅展示」，不渲染假开关；需带参但 spec 未提供类型定义的动作会被过滤，避免点了必失败。
- **对话操控**：机主说「把客厅灯打开」，Agent 调用 `mijia-control_control` 执行；对话上下文会注入当前设备清单（可在设置里关闭）。控制类工具在 Agent 动手前会先向你确认，除非你本轮已明确直接下令。
- **网络 / 蓝牙提示**：运行时检测本机网络与蓝牙可用性，缺失时在页面顶部提示「可能无法操控相应设备」。

## 界面与动画

- **液态玻璃质感**：淡粉渐变底 + 日光光晕与缓慢旋转的太阳光斑（90s 循环，`prefers-reduced-motion` 时自动停用）；卡片深模糊 + 内高光。
- **底部抽屉动画**：设置面板与设备详情从屏幕底部**由下而上滑入并逐渐减速**（`cubic-bezier(.16,1,.3,1)` 强 ease-out），关闭时沿同一条曲线**时间反向**滑出（起步慢、加速离场），遮罩同步淡入淡出。
- **交互微动效**：设备卡片鼠标跟随光圈、点击按压回弹（scale 0.98）；玻璃风确认弹窗淡入 + 上浮（pop-in）；开关拨杆、滑块、下拉均与粉紫主题联动的过渡动画。

## 提供给 Agent 的工具

| 工具 id | 作用 |
| --- | --- |
| `mijia-control_list_devices` | 列出可操控设备（名称 / 类别 / 房间 / 在线 / did） |
| `mijia-control_status` | 查询连接与扫描状态 |
| `mijia-control_control` | 操控设备：`on`/`off`/`toggle`/`set`(siid,piid,value)/`call`(siid,aiid,in) |
| `mijia-control_get_state` | 读取设备的 MiOT 属性值 |

## 依赖

仅申请宿主 `secrets` 能力（加密保存登录 token）。不写入工作区文件、不读取对话、不调用模型、不申请调度器（后台扫描用插件自有定时器实现，插件停止时清理）。

## 网络访问与数据存储（审核须知）

- **网络访问**：仅访问小米官方云端与公开 spec 库，用于登录与设备控制：
  - `https://account.xiaomi.com`（扫码登录）
  - `https://sts.api.io.mi.com`（登录回调）
  - `https://api.io.mi.com/app`（设备列表 `home/device_list`、房间 `v2/homeroom/gethome_merged`、属性读写与动作 `miotspec/prop/get|prop/set|action`）
  - `https://miot-spec.org/miot-spec-v2`（**只读**获取设备型号的 MIoT-Spec 能力表，用于自动生成功能控件；与 Home Assistant / python-miio 同源）
- **凭据存储**：登录 token（`userId` / `serviceToken` / `ssecurity` / `passToken`）仅经宿主 `secrets` 加密保存于本机，**绝不明文落盘**；退出登录即删除。
- **本地数据**：偏好设置、设备缓存、以及 MIoT-Spec 索引与单型号能力表（公开数据）经宿主 `ctx.storage`（插件私有目录）保存，不含隐私数据；卸载 / 退出即失效。
- **子进程**：不启动任何子进程。局域网探测使用 Node 内置 `dgram` 发送一次 UDP 广播（`255.255.255.255:54321`），失败静默降级，不影响云端功能。
- **无** `eval` / 动态 `require` / 代码混淆；入口仅 `require` 内置模块（`node:os` / `node:path` / `node:dgram`，经由自包含 `lib/` 模块使用 `node:crypto`）、`electron`（创建面板窗口）与 `./lib/micloud.cjs`、`./lib/miot_spec.cjs`。

## 使用前提与已知边界（务必先读）

1. **它是「控制面」，只能命令已经挂在米家云上的设备。** 纯蓝牙 / 蓝牙 Mesh 设备需家里有一台**米家蓝牙（Mesh）网关**让其上线，否则云端够不着、本插件也无法操控（会给出明确提示）。
2. **「能连米家」不等于「能被米家控制」。** 个别廉价第三方设备只登记、不开放可写属性；这类设备在本插件里同样无法操控。
3. **走的是社区公开的米家云端接口（非官方个人 API）。** 与 Home Assistant / python-miio 同源；若小米改版端点或鉴权，可能需跟进适配。
4. **功能控件基于公开 MIoT-Spec 自动生成。** 主流小米 / 米家型号能自动渲染开关、滑块、下拉、动作按钮；**个别型号若未公开到 MIoT-Spec 库**，面板会提示并退回「高级」区手动填 siid/piid/aiid。
