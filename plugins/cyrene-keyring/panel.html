      这是什么

      钥匙环把密码、2FA 验证码、API Key 和安全笔记收进一个本机加密库。数据只保存在这台电脑上，不上传，也不经过任何服务器。

      库文件用 AES-256-GCM 加密，密钥由主密码经 scrypt（N=131072 / r=8 / p=1）派生，或由 Windows Hello 通过 DPAPI 包裹。没有主密码或 Hello，打不开库。

      四档权限

      每个条目单独设一档，决定 Agent 能拿它做什么。

      仅面板Agent 连请求都发不出，只能在面板里查看和复制。
      每次确认Agent 发起请求后进「等待你确认」，你允许后值进剪贴板；工具返回值里没有明文。
      本次解锁免确认第一次允许时可以勾选「本次解锁都允许」，之后同一解锁周期内直接执行，值仍只进剪贴板。
      明文直读不进确认区，Agent 直接拿到明文。明文会进入对话记录，无法撤回。

      怎么用

      1. 第一次打开先设主密码（至少 12 位），库就建好了。
      2. 在「条目」页点「添加」，选类型填内容。2FA 可以粘贴 otpauth 链接、手动填 secret，或识别二维码截图。
      3. Agent 想取用时，「等待你确认」会出现请求。允许后值进剪贴板，30 秒后自动清除。
      4. 「设置」页可以换主密码、开关 Hello、调自动锁、导出加密备份。

      自动锁定

      手动锁定或关闭 Cyrene 会立刻清掉内存里的密钥，同时清空待确认请求、一次性令牌和本次解锁的免确认名单。无操作锁定默认 5 分钟，可以关掉；面板最小化后另有独立的锁定时间，默认 10 秒。

      备份

      导出的是加密备份，用导出时另设的密码保护。换设备时选这个文件加密码就能导入。主密码和导出密码都不保存在任何地方，丢了就打不开。

      已知限制

      • 不防同一 Windows 账户下的恶意程序。它能读进程内存，也能读剪贴板。
      • 复制到剪贴板的值 30 秒后自动清除；这段时间里其他程序可能读到它。
      • 「明文直读」档会把明文直接交给 Agent，进入对话记录，无法撤回。
      • Windows Hello 的安全性取决于系统账户和硬件，不额外增加一层独立密钥。
      • 这是自用工具，没有经过第三方安全审计。
