# local-asr 本地语音识别插件（v0.4.9 · 通话自动接管版）

> **一句话介绍**：让昔涟听懂你说话。你对着麦克风说中文，插件在**你自己的电脑上**把语音变成文字，自动发给昔涟——不联网上传、不需要装 Python、不需要显卡、不需要敲命令。

---

# 🎵 边听歌边聊天（v0.4.0 新功能：唤醒词门控）

**问题**：放音乐时开语音通话，麦克风会把扬声器的歌词/伴奏录进去，昔涟收到一堆歌词。

**解决**（小爱同学模式）：
1. 插件面板 → 展开「唤醒词门控（小爱模式）」→ 模式选 **「仅音乐播放时（推荐）」** → 保存
2. 音乐播放时，插件自动激活门控：
   - 你说「**昔涟，暂停音乐**」→ 唤醒词命中，去掉前缀后提交「暂停音乐」→ 昔涟停歌回你
   - 你说「**下一首**」「**声音大一点**」这类音乐快捷指令 → 直接放行
   - 歌词、环境杂音、无关聊天 → **自动拦截**（面板状态栏显示"🎵门控中"，可看到拦截计数）
3. 音乐一停，门控自动解除，恢复普通语音对话
4. 唤醒词默认「昔涟 / 小昔」，可在面板改成任意词（最多 6 个，逗号分隔）

> 音乐状态来自 Cyrene v1.2.2+ 内置音乐工具（`music:get-status` 通道）。旧版 Cyrene 无此通道时，音乐模式自动退化为不拦截。

# 📖 小白安装指南（照着一步步做就行）

## 开始之前，你需要准备

| 需要什么 | 说明 |
|---|---|
| Cyrene **v1.2.1 或更新** | 菜栏「帮助 → 关于」可看版本。旧版本没有插件系统，请先升级 |
| 约 250MB 磁盘空间 + 网络 | 第一次使用要下载识别引擎（只下一次，之后离线可用） |
| 一个麦克风 | 笔记本自带麦克风也行 |
| （可选）TTS 的 API Key | 如果你想让昔涟"开口说话"。没有的话昔涟只会打字回复，语音识别照常能用 |

---

## 第 1 步：下载插件压缩包

**方法 A（推荐，收录后可用）**：打开 Cyrene → 插件面板 → 插件下载页 → 找到 **local-asr** → 下载 zip。

**方法 B（手动下载）**：用浏览器打开本插件发布页，下载 `local-asr-x.x.x.zip` 文件（注意：**下载的是 zip 压缩包，不用解压**）。

## 第 2 步：导入插件

1. 打开 Cyrene
2. 在聊天窗口找到**插件面板**按钮，点开
3. 点面板右上角的 **「+」** 按钮
4. 选中刚下载的 zip 文件 → 确认导入
5. 导入后插件列表里会出现 **本地语音识别**，确保开关是**启用**状态

> 如果之前装过旧版本，导入时提示"已存在，是否替换"，选**替换/确认**即可，不会丢失已下载的引擎。

## 第 3 步：打开插件面板，认识三盏灯

点插件列表里的 **本地语音识别**，会弹出一个控制窗口。窗口上半部分是**体检区**，四个指示灯：

| 灯 | 叫什么 | 什么意思 |
|---|---|---|
| 🟢 绿 | ASR 引擎 | 语音识别已就绪（能看到"GPU cuda:0"说明在用显卡，纯文字说明则是 CPU） |
| 🟢 绿 | TTS 服务 | 昔涟的声音服务就绪 |
| 🟢 绿 | 通话设置 | Cyrene 的通话配置正确 |
| 🔴 红 | CPU 引擎 "未安装" | **如果你有外置服务，这个红是正常的**，不用管它。没有外置服务时点「安装引擎」按需下载 |

第一次打开时灯会显示"检测中…"，几秒后出结果。

## 第 4 步：第一次使用——点「安装」下载引擎（只此一次）

如果你的电脑**没有**语音识别环境，面板会提示安装。下载**不会自动开始**——由你点**「安装 (约250MB)」**按钮确认后才启动（约 250MB，走国内阿里源，速度通常很快）：

- 面板上会出现**进度条**：显示 `已下载/总量 · 百分比 · 下载速度`
- **中断了也不用怕**：断网、关掉 Cyrene、点取消——下次都会**从断点继续**，不会重头下载
- **安全**：每个文件下载完成后都会先做 **SHA-256 哈希校验**，校验通过才会解包使用，防止下载源内容被替换

下载完成后会自动解包，日志区显示"轻量引擎安装完成"。**这些都在后台进行，你可以先去干别的。**

## 第 5 步：修复通话设置（如果「通话设置」是红灯）

1. 找到 **「一键修复」** 按钮，点它
2. 看到绿色横幅提示"修复完成，请重启 Cyrene"
3. **马上做第 6 步**（重启越快越好，原因见 FAQ）

> 修复前插件会自动备份你的配置文件（`.local-asr-backup`），改坏了随时能还原。

## 第 6 步：完全退出并重启 Cyrene

**注意：不是最小化到托盘！** 要彻底退出：

1. 关闭 Cyrene 所有窗口
2. 看一眼系统托盘（屏幕右下角），如果还有 Cyrene 图标 → 右键 → 退出
3. 重新打开 Cyrene

> 为什么要重启：修复写入的是配置文件，Cyrene 正在运行时会在退出前用内存里的旧配置覆盖回去。重启后设置才真正生效。

## 第 7 步：开始语音对话 🎤

1. 打开和昔涟的**语音通话**（或普通聊天窗口）
2. 打开插件面板，点 **「接管通话」**（在聊天窗口就点「接管聊天」）
3. 面板上出现红点闪烁 + "采集中"，**对着麦克风说话**（说完一句稍微停顿一下）
4. 你说的话会变成文字自动发出去，昔涟回复你
5. 聊完了点 **「停止」** 释放麦克风

**使用规则**：昔涟回复的时候插件会暂停收音（防止把她的声音录进去），等她回复完你再继续说。一句话一句话地说，识别效果最好。

# 🚦 出问题了？对照这张表

| 现象 | 原因 | 怎么办 |
|---|---|---|
| ASR 灯红 + 显示"未启动" | 没有识别环境 | 点「安装引擎」下载内置引擎（需确认后才开始） |
| 下载很慢/失败 | 网络问题 | 中断没关系，会自动断点续传；点取消再点安装重试 |
| 通话设置灯红 | Cyrene 通话配置不对 | 点「一键修复」→ 立刻重启 Cyrene |
| 修复后重启又变红 | 重启前改过 Cyrene 设置页 | 再点一次「一键修复」→ 立刻重启 |
| 通话一直"连接出错" | 通话设置没修复或没重启 | 同上 |
| 接管后没有文字出来 | 麦克风没声音/被其他程序占用 | 检查 Windows 声音设置的输入设备；关掉其他占用麦克风的软件 |
| 识别结果不准 | CPU 引擎精度略低 | 说话离麦克风近一点、放慢语速；有条件的用户可搭外置 GPU 服务（见下文"高级"） |
| 昔涟不说话只有文字 | TTS 未配置 | 在 Cyrene 设置里配置 TTS 引擎（如 minimax / mossland，自备 Key） |

**日志区**：面板下方的"流程日志"会记录每一步动作，遇到问题截图这个区域发 issue 最有助排查。

# ❓ 常见问题（FAQ）

**Q: 引擎什么时候下载？会偷偷下载吗？**
A: 不会。插件启用/体检时只做**检测和提示**，250MB 下载**必须由你点面板上的「安装」按钮确认后才开始**。下载过程有进度条随时可取消，中断自动断点续传。

**Q: 下载的文件安全吗？**
A: 每个文件（引擎二进制、模型、词表）都内置了发布方核对过的 **SHA-256 哈希值**，下载完成后先校验哈希、通过才落盘解包使用；校验不过自动丢弃并换源，不会加载被篡改的文件。

**Q: 下载到一半断网/退出 Cyrene 了怎么办？**
A: 下次自动从断点续传（已下载的部分不重下）。面板上会显示"已保留 XXX MB 断点"。如果切换了下载镜像源，会重新从头下载——这是防止不同源的文件拼在一起损坏，属于保护机制。

**Q: 下载的东西装在哪？占多少空间？**
A: 装在 Cyrene 插件的私有数据目录 `engine/` 文件夹里，总共约 252MB。升级插件版本不会丢，卸载插件才会删除。

**Q: 我的语音会被上传到网上吗？**
A: **不会。** 语音只在你电脑上识别（CPU 引擎或本机服务），全程不出本机。插件唯一访问网络的行为是下载引擎文件（来自阿里 npm 镜像和 ModelScope 魔搭），详见下方"透明度披露"。

**Q: 为什么通话设置要用 mossland 而不是 local？**
A: Cyrene v1.2.1 里 "local" 是个占位选项，没有实际实现，选它通话会直接"连接出错"。mossland 引擎只检查 Key 非空、不联网——本插件接管输入后 mossland 实际收不到任何音频，只是"陪跑"让通话能建立，识别全部由本插件完成。

**Q: 一句话识别一次，能边说边识别吗？**
A: 目前是"说完一句 → 停顿 → 识别提交"的模式（静音 0.8 秒判定一句话结束）。这是为了防止把昔涟的回复声录进去，也是当前识别准确率最好的方式。

# ✨ 版本特性（v0.4.9）

- **通话自动接管**：发起语音通话后无需任何手动操作，插件自动检测通话开始并接管语音输入（面板可一键关闭该行为，设置持久化保存）
- **纯 SDK 接口实现**：自动接管通过官方插件 SDK 的 `speechInput.acquire({target:"active-call"})` 契约探测完成，**不 require 宿主任何内部模块**，上游重构内部实现不受影响
- **无面板也能开麦**：自动接管触发时若插件面板未打开，自动创建隐藏采集窗口启动麦克风，通话结束后自动回收
- **供应链安全**：全部下载文件（引擎二进制 ×2 + 模型 + 词表）按镜像源硬编码 SHA-256，下载后先校验哈希再落盘；引擎加载脚本在每次启动识别子进程前再复验一次哈希（安装时记录于宿主 storage），防安装后被替换
- **唤醒设置真实生效**：面板里的唤醒词/门控模式保存后经 IPC 写入宿主 storage 并即时生效（主进程运行态同步更新），UI 显示与主进程行为始终一致
- **显式确认安装**：启用只做检测提示，250MB 下载由用户在面板点「安装」确认后才开始
- **唤醒词门控（小爱模式）**：音乐播放时过滤歌词/杂音，说「昔涟」唤醒后正常对话，音乐快捷指令直通
- **零环境**：启用后自动体检，没有环境时引导一键下载轻量引擎（sherpa-onnx CPU 版，约 250MB，全走国内源）
- **断点续传**：下载中断后从断点继续，不重下已下载部分
- **进度可见**：实时显示 `已下/总量 · 百分比 · MB/s`
- **取消即时生效**：点「取消」立刻断开连接，已下载部分保留
- **双引擎自动切换**：外置 FunASR 服务（GPU）优先 → 不可用自动切内置 CPU 引擎
- **一键修复**：自动修正 Cyrene 通话配置（写前备份）

识别优先级：
1. 外置 FunASR 服务（127.0.0.1:8328，GPU，老用户已有）→ 自动优先
2. 内置轻量引擎（CPU，确认后下载安装，离线可用）
3. 都没有 → 面板一键安装

# 🔧 技术说明（进阶用户/审核者看）

- 轻量引擎 = sherpa-onnx 1.13.7（NAPI 原生插件）+ paraformer-zh int8 模型
- CPU 识别实测：5.6 秒音频约 220ms（实时率 ~4%），全异步接口不卡界面
- 下载源（已验证国内直连）：
  - 二进制 8.7MB：`registry.npmmirror.com`（阿里 npm 镜像）
  - 模型 243MB：`modelscope.cn`（阿里魔搭，含多个镜像回退）
- 断点续传实现：`.part` + `.part.json`（记录来源 URL）→ 同源 HTTP Range 续传；
  跨源不续传（防止不同源的文件字节流拼接损坏），服务器不支持 Range 时自动从头下
- 安装位置：Cyrene 插件私有数据目录（`engine/`），插件升级不丢失

## 为什么不把环境打进 zip

Cyrene 插件 zip 硬限制：包体 ≤50MiB、解压总量 ≤200MiB。
即使是最轻的 CPU 引擎（二进制 23MB + 模型 243MB）也无法塞进 zip，
所以采用"启用后在线安装"——zip 本体仅 20KB。

## 高级：外置 FunASR 服务（GPU 提速）

已有 Python 环境的用户可跑外置服务（`asr_server.py`，FunASR paraformer），
插件检测到 8328 在线会自动优先走 GPU。面板底部"服务配置"可指定启动命令，
体检发现没启动会自动拉起。

# 🔍 透明度披露（权限与行为说明）

**网络访问**（全部明文可审计，见 `index.cjs` 顶部常量）：

| 目标 | 用途 | 传输内容 |
|---|---|---|
| `registry.npmmirror.com` | 下载 sherpa-onnx 推理二进制（8.7MB tgz） | 仅文件下载 |
| `modelscope.cn`（含 2 个镜像仓库） | 下载 paraformer int8 模型（243MB）+ 词表 | 仅文件下载 |
| `127.0.0.1:8328` | 探活/调用本机 FunASR 服务（可选） | WAV 音频片段（本地回环，不出本机） |
| `127.0.0.1:8327` | 探活本机 TTS 网关（可选，仅状态检查） | 空 JSON |

语音数据**只在本机识别**（内置 CPU 引擎或本机 FunASR），不上传任何云端。

**文件写入**：

| 位置 | 内容 |
|---|---|
| 插件私有 storage 目录（`engine/`） | 下载的引擎二进制、模型、`.part` 断点文件 |
| `%APPDATA%/live2d-cyrene/app-settings.json` | **仅当用户点「一键修复」**：写入 `asrEngine`/`ttsMosslandKey` 两个字段（写前自动备份为 `.local-asr-backup`）。这是让语音通话能建立的必要配置 |

**子进程启动**（仅当用户在「服务配置」里指定了启动命令，或点「启动服务」按钮）：

- 启动用户指定的可执行文件（如 `start_asr_silent.bat` / `pythonw.exe`），路径经文件选择器选取后存于插件 storage
- `detached` 常驻，插件停用不杀进程（外置服务生命周期独立）

**密钥**：本插件不处理任何 API 密钥（不读、不存、不打印）。`ttsMosslandKey` 写入的是无意义占位字符串（宿主引擎只校验非空）。

**已知限制**：内置引擎为 CPU 推理，识别质量略低于 GPU 版 FunASR；TTS（昔涟的声音）不在本插件职责内，需在 Cyrene 设置里另行配置。
